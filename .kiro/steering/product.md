# Product

SATAN Reborn is a Kiroween 2026 Resurrection project inspired by SATAN (1995).
Its new purpose is auditing a local code folder, not scanning live networks.

Prioritize a useful, safe offline demo, clear findings, and a polished 1995-retro
spooky browser report. Use CRYPT/HAUNT/SPOOK/WHISPER consistently alongside
standard severity names. Soul Integrity is a heuristic, never a security claim.

Never execute scanned applications or install their dependencies. Never use
real secrets in fixtures. Never expose credential values in outputs. OSV
network access requires explicit --osv and sends package metadata only.

The haunted app is intentionally insecure text, not an application to repair,
run, deploy, or build. Keep its obvious FAKE labels. Preserve privacy warnings.
